# Fundraising Arcade Games
The purpose of this project is to reach a wide variety of audiencies, from old alumni 
to young kids. To accomadate for this audience we will be creating a game emulator style
of a collection of arcade games. Each game should be small, lasting at most 2 minutes to
play.
## Games
The games themselves will be very small and should be able to be completed by a single 
developer with help if needed. They should be easy to play and intuitive, no complex
movement or controls. Single or two button games would be ideal: pong, jumper, simple 
platformers should be the upper end.
## Style
The style of these games should reflect their simple nature, but remain visually distinct
in order to keep things interesting. Free assets are allowed, but feel free to ask the 
designers if you have something specific to COFO in mind. The theme will revolve around
COFO in general.
The Point, the keeter, the chapel. Games around those scenes would be cool.
## Unified Menu System
All of the games will have a single pause menu asset. This will help to cut back on 
development, as well as give a point of clarity through the games.
Along with this there will be a single main menu with a carasole that will rotate
with the game icons to represent what the game is.
Ideally only one person will work on this, and then everyone would be able to 
implement this into their projects. This should be worked on as one of the first 
things so that a unfied menu can be the standard and not the exception.
